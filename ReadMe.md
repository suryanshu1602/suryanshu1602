# 💫 About Me:
I'm a QA Lead with 12+ years of experience in enterprise web, mobile, API, integration and cloud applications. For the last four years I've led a 6-member QA team across 3 Agile pods at Motorola Solutions, owning test strategy, release readiness, quality gates and quality metrics.<br><br>On the technical side, I work with Playwright, TypeScript, Cucumber/BDD, API testing (Postman, RestAssured, SQL), Jenkins CI/CD and AWS test environments. My team's regression cycle came down from 8 hours to 4 with parallel runs in Jenkins. I'm also hands-on with AI-assisted QA, using N8N, Langflow and AI agents for test generation and defect triage, which cut manual triage effort by about 60%.<br><br>Earlier in my career at Tech Mahindra, I moved from Senior Software Engineer in Test to Lead, working on enterprise test strategies, API and integration testing, and JMeter performance testing.<br><br>I hold 9 Salesforce and 2 AWS certifications, and I'm happy to connect on quality engineering, test leadership and AI in QA.
